# PADEN: Creator Connect

# PROMPT MESTRE — PADEN MVP

Crie uma aplicação web responsiva chamada **PADEN**, um marketplace que conecta **creators digitais a empresas e marcas** para oportunidades de publicidade, collabs, experiências, permutas e campanhas.

IMPORTANTE: quero construir um **MVP funcional, moderno e profissional**, mas sem adicionar complexidades desnecessárias. Não invente funcionalidades que não estejam descritas neste prompt.

A PADEN não é uma agência de influencers e não participa da negociação comercial entre empresa e creator.

A função central da PADEN é:

**Encontrar → Demonstrar interesse → Dar Match → Liberar contato.**

Depois do Match, creator e empresa negociam diretamente fora da plataforma.

---

# 1. IDENTIDADE DA MARCA

Nome:

**PADEN**

Conceito:

**Creators encontram marcas. Marcas encontram creators.**

A PADEN deve transmitir:

* criatividade;
* confiança;
* modernidade;
* proximidade;
* oportunidade;
* profissionalismo;
* juventude;
* tecnologia.

## Cores

Utilizar:

* roxo como cor principal;
* laranja como cor de destaque;
* branco/off-white como fundo;
* grafite para textos.

Evitar roxo e laranja excessivamente saturados ou infantis.

Quero uma aparência premium, moderna e jovem.

## Logo

Criar inicialmente uma identidade tipográfica simples para PADEN e um placeholder de símbolo.

O conceito futuro do símbolo será:

**duas formas diferentes que se encontram e se encaixam**, representando:

Creator + Marca = Match PADEN.

NÃO utilizar:

* câmera;
* coração;
* símbolo do Instagram;
* @;
* aperto de mãos;
* um simples “P” genérico.
